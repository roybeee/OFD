# ODA 직원 홈과 위치 기반 출퇴근

직원(`store_staff`) 계정은 로그인 후 **직원 홈**에서 출퇴근, 월간 근무표, 매장 공지를 확인한다. 매장 바깥에서도 근무표와 공지를 볼 수 있으며, 출퇴근 등록에 위치 조건을 적용한다. 설치형 PWA와 HTTPS 브라우저에서 같은 계정·서버 기록을 사용한다.

## 관리자가 처음 준비할 항목

1. 계정 관리에서 직원을 해당 매장에 배정하고, 인사관리의 직원 정보에 로그인 계정을 연결한다. 계정이 연결되지 않으면 본인 출퇴근을 기록할 수 없다.
2. **인사관리 → 설정 → 출퇴근 위치**에서 매장 주소를 확인한다. 매장 현장에서 현재 위치를 가져오거나 지도에서 확인한 위도·경도를 입력하고 저장한다. 주소 텍스트만으로 좌표가 자동 변환되지는 않는다. 기준 위치와 반경 200m를 확인한 뒤 저장해야 한다.
3. **근무 일정**에서 해당 월의 근무·휴무 일정을 만들고 게시한다. 초안과 취소된 일정은 직원 근무표에 나타나지 않는다.
4. **홈·인사이트**에서 공지를 작성하고 게시한다. 고정 공지는 먼저 표시되며, 초안·보관 공지는 직원에게 공개되지 않는다.

실제 매장 주소나 좌표를 임의의 예시로 채우지 않는다. 이미 등록된 매장 주소는 설정 화면의 입력 기본값으로 제공한다. 출퇴근 기준 위치를 변경하면 이후 등록부터 새 위치가 적용된다.

관리자 **홈·인사이트 → 직원 화면 준비 현황**에서 저장된 위치, 근무를 시작한 재직 직원의 활성 계정 연결, 당월 게시된 일정, 게시된 공지를 확인하고 해당 관리 화면으로 이동할 수 있다. 휴직·퇴직·입사 예정 직원은 이 준비 현황의 인원 집계에서 제외한다. 근무표와 공지의 게시 여부는 정보 공유 현황이며 출퇴근 등록을 막는 추가 조건이 아니다.

직원의 **내 인사 메뉴 → 도움말**은 직원 전용 이용 순서와 위치 권한·측정 오차·통신 오류·퇴근 누락 안내를 제공한다. 출퇴근과 근무표 안내에서 직원 홈으로 돌아가거나, 본인 근무 기록·휴가·급여·문서 화면을 바로 열 수 있다. 관리자용 도움말에는 기준 위치 저장과 근무표 게시 순서를 포함한다.

## 직원의 하루

| 항목 | 화면 동작 |
|---|---|
| 출퇴근 | 서버의 마지막 출퇴근 기록을 기준으로 출근/근무 중/퇴근 상태를 보여준다. 앱을 열었다는 이유로 자동 타각하지 않는다. |
| 위치 확인 | 브라우저에서 위치 사용을 허용한다. 출근 또는 퇴근 등록을 누를 때 새 위치를 다시 측정하고 서버가 검사한다. |
| 근무표 | 서울 시간 기준 당월을 먼저 표시하고, 본인 일정과 공개된 매장 근무표를 구분해 확인한다. 야간 교대와 휴무를 표시한다. |
| 매장 공지 | 게시된 공지를 고정 여부와 게시 갱신 순서로 확인한다. |
| 내 인사 메뉴 | 본인 휴가, 결재, 비용, 공개된 급여 명세와 개인 문서 등 기존 인사 기능에 접근한다. 관리자 설정·채용 메뉴는 직원 홈에 노출하지 않는다. |

## 서버의 위치 판정

등록 요청은 로그인 계정·배정 매장·연결된 본인 직원 정보를 확인한 후 처리한다. 현재 위치의 위도·경도·정확도·측정 시간을 입력받으며, 클라이언트가 전달한 허용 여부나 거리를 신뢰하지 않는다.

- 반경은 **200m 고정**이다. 서버가 저장된 매장 기준점과 측정 위치의 거리를 계산한다.
- 정확도는 0m 초과·50m 이하여야 한다. **거리 + 측정 오차가 200m 이내**여야 등록한다. 경계 부근에서는 위치를 더 정확히 잡거나 매장 가까이 이동해야 한다.
- 측정 시점은 서버 시간 기준 60초 이내여야 하며, 10초를 초과하는 미래 시각은 허용하지 않는다.
- 기준 위치 미설정, 위치 권한 거부, 위치 서비스 오류, 측정 시간 초과, 정확도 부족, 반경 바깥에서는 타각이 생성되지 않는다. 근태 정정이 필요하면 관리자에게 요청한다.
- 직원이 수동으로 작성한 근무는 관리자 승인 대상으로 남는다. 수동 입력으로 위치 검증을 우회해 승인된 근무를 만들 수 없다.
- 중복 요청·동시 변경·권한·재직 기간·근태 마감 검사는 기존 HR 트랜잭션과 함께 적용한다.

출퇴근 시각은 서버 시간을 사용한다. 원시 타각에는 확인된 거리·정확도·검증 시간·기준 위치 버전 정보만 저장하며, 직원의 정밀 위도·경도는 저장하지 않는다. 백그라운드 위치 추적과 이동 경로 수집은 하지 않는다.

## 한계와 검증 범위

이 기능은 브라우저가 제공한 위치를 검증한다. 기기의 모의 위치, 변조된 클라이언트나 운영체제까지 판별하는 장치 인증 기능은 아니다. 실내 위치 품질은 기기와 환경에 따라 달라질 수 있다. 관리자 현장 좌표 설정과 실제 직원 휴대전화의 위치 허용은 운영 현장에서 수행해야 한다.

자동 검증은 정상·경계·바깥·오래된 위치, 권한과 매장 범위, 중복 등록, 게시 일정·공지 공개 범위, 실제 React/API 저장 연결을 확인한다. 운영 배포 후에는 사이트의 위치 사용 정책 헤더와 신버전 파일·서버 준비 상태를 확인한다. 휴대전화의 실제 GPS 측정 자체를 자동 테스트로 인증하지 않는다.

브라우저 동작 근거: [Geolocation getCurrentPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/getCurrentPosition), [Permissions-Policy geolocation](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/geolocation).

## FLEX 참고 모바일 화면 구성

- 하단 **오늘·일정·할 일·더 보기**가 주 탐색을 담당하며, 개인 인사 화면에서도 하단 메뉴로 이동한다. 오늘 화면의 출퇴근 바는 하단 메뉴 위에 고정한다. 근무 등록을 누르면 위치 확인 시트를 열며, 실제 출퇴근은 버튼을 명시적으로 눌러 수행한다.
- 오늘: 메뉴·공지 검색, 근무·휴가·미팅 바로가기, 오늘 일정·할 일 수, 주간 승인된 근무 시간과 배정된 목표, 공개 매장 근무표, 공지. 승인 대기는 승인 시간에 포함하지 않고 별도 표시한다. 설정되지 않은 목표를 임의로 40시간으로 표시하지 않는다.
- 일정: 주간/월간 전환, 날짜·동료 필터, 본인 근무/휴가/미팅과 동료의 공개 근무표. 미팅에 저장된 시각이 없으므로 시간 미지정으로 표시한다. 선택한 월의 본인 공개 근무표를 .ics 파일로 내보낼 수 있으며, 외부 캘린더 자동 동기화는 아니다.
- 할 일: 현재 승인 순서·대결 조건을 충족하는 결재, 본인에게 배정된 미팅 할 일과 작성 중인 평가. 요청한 일에는 본인 신청의 진행 상태를, 참조에는 결재선에 참여하는 다른 단계의 문서를 표시한다. 별도의 참조자 지정 기능을 구현한 것은 아니다.
- 더 보기: 구성원·회사 정보, 인사 기능 메뉴, 기기별 즐겨찾기와 글자 크기. 기기 설정에는 메뉴 ID와 글자 크기만 저장하며, 직원 정보는 브라우저 저장소에 보관하지 않는다. 외부 전자서명·앱 종료 후 푸시 리마인더·동료 인정·미니게임은 이 변경에 포함하지 않는다.
- 버튼은 모바일 44px 이상, 입력은 46px, 저장 버튼은 48px를 기준으로 한다. 관리자 직원·조직 검색과 필터, 하단 시트 입력도 같은 규칙을 적용한다.
