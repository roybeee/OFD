# ODA를 내 Mac에서 실행하기

이 패키지는 **한 대의 컴퓨터에 저장하는 ODA 월 정산 프로그램**입니다. 매장 계정·월 정산·업로드한 원본 증빙은 전용 PostgreSQL 데이터베이스에 저장됩니다. 종료하거나 다시 실행해도 유지됩니다. 인터넷에 배포된 서비스나 서명된 Mac 설치 앱은 아닙니다.

현재는 실행 구성을 구현하고 빌드·API·화면·실행기 자동 테스트를 통과한 개발본입니다. 이 개발 환경에는 Docker와 실제 PostgreSQL이 없어 컨테이너 기동·재시작·백업 복구를 직접 검증하지 못했습니다. 실제 매장 자료 입력 전 해당 컴퓨터에서 확인이 필요합니다.

## 처음 실행

1. [Docker Desktop 공식 Mac 설치 안내](https://docs.docker.com/desktop/setup/install/mac-install/)를 따라 설치하고 실행합니다. Docker Engine이 준비되어야 합니다. 기업의 직원 수나 연매출에 따라 유료 구독이 필요한 이용 조건을 설치 전에 확인합니다.
2. 받은 ZIP 전체를 풀어 폴더를 Mac에 보관합니다. `Start-ODA.command`를 더블 클릭합니다. 처음에는 이미지 다운로드와 프로그램 빌드가 필요하므로 인터넷 연결이 필요하고 몇 분 이상 걸릴 수 있습니다.
3. 준비가 끝나면 브라우저가 **http://127.0.0.1:4175**를 엽니다. 처음 한 번 화면 안내에 따라 관리자·매장·계약 당사자 계정을 등록합니다. 초기 등록은 비어 있는 전용 DB에 한 번만 허용됩니다.
4. 등록한 계정으로 로그인하고 정산 월을 선택합니다. 매출·배달·비용·은행 파일을 올리고 확인이 필요한 항목을 검토합니다.

macOS가 출처를 확인할 수 없다고 표시하면 파일 위치와 내용을 확인한 뒤 [Apple의 개별 앱 열기 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40616/mac)를 따릅니다. 시스템 설정 → 개인정보 보호 및 보안에서 해당 파일에 대해 **그래도 열기**를 선택하는 방식입니다. 실행 권한이 보존되지 않아 열리지 않는 경우 터미널에서 `bash `를 입력하고, 압축 푼 폴더의 `infra/scripts/oda-local.sh` 파일을 터미널로 끌어온 뒤 ` start`를 붙여 실행할 수 있습니다.

Node.js·npm·PostgreSQL을 Mac에 따로 설치할 필요는 없습니다. Docker Desktop이 필요합니다. Windows용 설치 파일은 이 패키지에 포함하지 않았습니다. Linux에서는 Docker Engine 및 Compose v2, Bash, OpenSSL, GUI 브라우저가 준비되어 있으면 `bash infra/scripts/oda-local.sh start`로 실행합니다.

## 매일 사용

다시 시작할 때는 `Start-ODA.command`를 엽니다. 실행 중인 동안 브라우저에서 `http://127.0.0.1:4175`에 접속합니다. 종료하려면 `Stop-ODA.command`를 엽니다. 브라우저 창만 닫으면 서버는 계속 실행됩니다. 컴퓨터를 재시작한 경우 Docker Desktop을 먼저 열어 주세요.

한 컴퓨터에서 A/B 각 계정으로 로그아웃·로그인하며 사용할 수 있습니다. 이 주소는 **이 컴퓨터에만** 연결됩니다. 휴대폰·다른 PC 접속이나 매장과 본사의 동시 원격 사용을 제공하지 않습니다. 그 용도에는 HTTPS 서버 배포와 별도 운영 설정이 필요합니다.

## 저장과 백업

- 계정·정산·증빙 원본: Docker 전용 볼륨 `oda-workstation-local_oda_local_postgres`.
- Mac 연결 설정: `~/Library/Application Support/ODA Workstation/local.env`.
- Linux 연결 설정: `${XDG_DATA_HOME:-~/.local/share}/oda-workstation/local.env`.

연결 설정과 암호화 키는 최초 실행 시 무작위로 생성되며 개발 소스에 포함되지 않습니다. 기본 관리자 비밀번호는 없습니다. 최초 등록 화면에서 직접 정합니다.

`Backup-ODA.command`를 열면 일관된 PostgreSQL 백업과 해당 DB에 맞는 연결 설정을 날짜별 폴더에 저장합니다. Mac에서는 `~/Library/Application Support/ODA Workstation/backups/`에서 찾을 수 있습니다. 백업 폴더에는 정산·증빙·계정 정보와 비밀 키가 있으므로 접근을 제한한 외장 저장소에도 복사해 두세요. 백업은 같은 디스크가 고장 나는 상황에 대비한 외부 복사까지 해야 의미가 있습니다.

**Docker Desktop의 볼륨 삭제·공장 초기화는 정산 데이터를 삭제합니다.** `Stop-ODA.command`는 데이터를 삭제하지 않습니다. 소스 폴더를 다른 곳으로 옮겨도 전용 볼륨과 연결 설정은 유지됩니다. 연결 설정만 없어지고 기존 볼륨이 남아 있으면 실행기는 새 키로 덮어쓰지 않고 복원을 안내합니다.

복원은 기존 데이터를 덮어쓰므로 자동 실행 버튼을 제공하지 않습니다. 기술 담당자가 현재 데이터도 먼저 백업한 후, 실행 서비스를 중지하고 백업의 `local.env`와 `oda.dump`를 함께 복원해야 합니다. 소스 ZIP만으로 사용 중인 정산 데이터가 복원되는 것은 아닙니다.

## 실제로 제공되는 기능과 범위

월 정산 자료·증빙을 DB에 저장하고, 수정 이력을 남기며, 계약 기준 배분액을 계산합니다. 계정 로그인과 접근 권한을 적용합니다. 파일 가져오기는 CSV·XLSX를 사용하며 PDF·이미지는 증빙으로 보관합니다. PDF·이미지 내용을 자동으로 읽는 OCR 기능은 아닙니다.

이 로컬 실행에서는 자동 은행 연결·외부 POS API·메일 발송·세금계산서 발행·실제 송금을 사용하지 않습니다. 비밀번호 재설정 메일도 발송하지 않습니다. 월 정산 외의 외부 처리 기능은 차단됩니다. ODA 증빙은 전용 DB에 보관하므로 이 모드에서 S3나 SMTP를 별도 연결할 필요는 없습니다.

## 실행이 안 될 때

- **Docker가 없습니다/준비되지 않았습니다:** Docker Desktop을 설치·실행하고 Engine이 준비된 후 다시 엽니다.
- **4175 포트를 이미 사용합니다:** 그 포트를 사용하는 프로그램을 확인해 종료하고 다시 엽니다. 포트만 임의로 바꾸면 브라우저 보안 설정과 맞지 않아 로그인·저장이 거부됩니다.
- **빌드 실패:** 인터넷 연결·디스크 여유 공간을 확인한 뒤 다시 실행합니다. 기존 데이터는 삭제하지 않습니다.
- **초기 설정 키가 필요합니다:** 주소를 직접 입력하는 대신 `Start-ODA.command`를 다시 열어 주세요. 실행기는 키를 URL의 fragment로 브라우저에 전달하며 서버 URL·일반 실행 출력에 기록하지 않습니다.
- **기존 데이터는 있지만 설정이 없다고 표시됩니다:** 백업의 `local.env`를 원래 위치로 복원합니다. 임의로 새 키를 만들어 기존 DB에 연결하지 않습니다.

기술 담당자는 `bash infra/scripts/oda-local.sh status`로 상태, `bash infra/scripts/oda-local.sh logs`로 최근 로그를 확인할 수 있습니다. `docker compose config` 전체 출력에는 비밀 값이 포함될 수 있으므로 대화나 공개 이슈에 붙이지 마세요.

## 기술 구성

`infra/docker-compose.oda-local.yml`은 OFD와 별도 프로젝트·DB·볼륨·네트워크를 사용합니다. 웹 포트만 `127.0.0.1:4175`에 연결하고 API·PostgreSQL 포트를 호스트에 공개하지 않습니다. 서비스 네트워크의 외부 연결을 차단합니다. API는 시작 시 DB 마이그레이션을 완료한 후 실행하며, 웹 준비 상태는 DB·마이그레이션 준비 여부를 확인합니다.

로컬 실행은 `APP_MODE=local`을 명시합니다. 기존 운영 모드의 S3·SMTP 요구사항을 완화하지 않습니다. 로컬 모드도 실제 로그인·고정 세션 키·PostgreSQL을 요구하고, 데모 사용자 헤더를 통한 접속은 허용하지 않습니다. 초기 등록은 생성된 키와 정확한 loopback Origin을 확인하고, DB에 계정이나 매장이 있으면 다시 허용하지 않습니다.
